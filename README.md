# Deep Learning Project

This repository contains a collection of deep learning notebooks focused on image classification and convolutional neural networks (CNNs).

## Contents

- CNN from Scratch
- Fashion MNIST Deep Learning Model
- Fashion MNIST using CNN
- Color Fashion MNIST CNN
- Image Classification using ResNet50
- Sequential Model

## Project Overview

The notebooks in this project demonstrate:

- Building CNNs from scratch
- Training image classification models on Fashion MNIST
- Working with colored image datasets
- Using transfer learning with ResNet50
- Experimenting with sequential deep learning models

## Environment Requirements

It is recommended to use Python 3.9+ and install Jupyter Notebook or Jupyter Lab.

Install dependencies using:

```bash
pip install notebook jupyter
```

Depending on your notebook usage, you may also need:

```bash
pip install tensorflow keras numpy matplotlib pandas sklearn
```

## How to Run

1. Open the project folder.
2. Launch Jupyter Notebook:

```bash
jupyter notebook
```

3. Open any `.ipynb` file and run the cells in order.

## Notes

- Some notebooks may require a GPU for faster training.
- TensorFlow/Keras versions may vary by environment.
- If you encounter dependency issues, create a virtual environment and install the required packages there.
